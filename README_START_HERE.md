# VARITRIX Creative Launch Kit

## Start
Open `index.html` in a browser; Arabic and English versions are linked. For publishing, upload the HTML, CSS and `assets/` directory together to a static host.

## Included
- Arabic and English responsive company-profile HTML pages
- Original brand PNGs: profile logo, Facebook cover, Instagram post/story, LinkedIn cover and website hero
- Facebook About, bio and pinned launch copy in both languages
- Customer inquiry workflow, Messenger reply template and CSV lead tracker
- Relevant original company and brand DOCX source files

## Brand
Navy #0E1B2F | Blue #2FACEF | Slate #53657B | Pale #EDF7FE | White #FFFFFF.

## Before publishing
1. Confirm Facebook URL `https://facebook.com/Varitrix` is owned and active.
2. Review business registration and brand/trademark availability.
3. Replace provisional contact details only with verified channels.
4. Test images/cropping on actual social platforms.
5. Add approved privacy policy, legal entity details, and real contact details before deploying as an official business website.
6. No backend or automated transactions are provided. Lead tracking is manual.
